Pengaturan koneksi Juun

Masukkan URL endpoint milikmu setelah workflow n8n dan API ESP32 tersedia. URL disimpan pada browser ini saja. Jangan masukkan API key rahasia ke halaman publik.

Dashboard mengirim JSON { message, source, requestType }. Workflow harus menerima POST dan mengembalikan JSON dengan field reply/output/text.
Contoh dari firmware proyek ini: /api/status. Browser dan ESP32 perlu berada pada jaringan yang dapat saling menjangkau. HTTPS page ke HTTP device mungkin diblokir browser; uji dari localhost.
Gunakan endpoint firmware /api/led. Jika dikosongkan, dashboard membuat endpoint ini dari URL sensor /api/status.
